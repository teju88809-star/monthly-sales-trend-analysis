# Monthly Sales Trend Analysis

## Project Overview
The Monthly Sales Trend Analysis project focuses on summarizing sales data by month and visualizing sales patterns using a line chart. It demonstrates essential data analytics techniques, including date conversion, monthly aggregation, chronological sorting, and data visualization.

## Objective
- Analyze monthly sales performance.
- Identify months with the highest and lowest sales.
- Visualize changes in sales over time.
- Practice data analysis using Excel and Python.

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas
- Matplotlib

## Dataset
**Dataset:** Sample Superstore Sales

The sample analysis includes published monthly sales values for January–June 2014. Sample Superstore is a fictional educational dataset.

## Project Files
- `Monthly_Sales_Trend_Completed_Task.xlsx` — Monthly sales table, line chart, and key findings.
- `Monthly_Sales_Trend_Completed_Task.pdf` — Analysis report and methodology.
- `Monthly_Sales_Trend_Theory_Complete.xlsx` — Theory and task documentation.

## Methodology
1. Convert the order date column into a valid date format.
2. Extract the year and month from each transaction date.
3. Group sales transactions by month.
4. Calculate the total sales for each month.
5. Sort the months chronologically.
6. Create a line chart to visualize the sales trend.
7. Identify key findings from the monthly summary.

## Key Findings
- March 2014 recorded the highest sales among the six months analyzed.
- February 2014 recorded the lowest sales.
- Sales increased sharply from February to March.
- Sales declined in April and May before recovering in June.

## Expected Outcome
The project demonstrates how monthly sales data can be summarized and visualized to identify trends and support data-driven decision-making.

## Limitations
The current analysis covers January–June 2014 only. The findings should not be interpreted as a full-year or multi-year sales trend.
